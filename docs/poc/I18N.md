## Nghiên cứu và quyết định

Đối chiếu tài liệu chính thức ngày 2026-10-11, lựa chọn **i18next 26.4.3 + react-i18next 17.0.16** cho React 19/Vite hiện tại. Phiên bản được pin trong `apps/web/package.json` và `pnpm-lock.yaml`.

| Lựa chọn | Khả năng và ảnh hưởng đến dự án | Đánh giá |
| --- | --- | --- |
| [i18next](https://www.i18next.com/overview/api) + [react-i18next](https://react.i18next.com/latest/usetranslation-hook) | Catalog JSON, hook cập nhật khi đổi ngôn ngữ, interpolation/plural, khởi tạo đồng bộ với resource đi kèm bundle; không cần pipeline trích xuất/biên dịch riêng | Phù hợp nhất với SPA hiện có và hai ngôn ngữ được yêu cầu |
| [React Intl / FormatJS](https://formatjs.github.io/docs/react-intl/) | ICU message và API định dạng phong phú; cần thống nhất descriptor/ICU và quy trình catalog khi chuyển lượng lớn chuỗi hiện có | Lựa chọn tốt khi dự án chủ động chọn ICU; không cần thêm cho scope hiện tại |
| [Lingui](https://lingui.dev/introduction) | Workflow macro, [extract/compile](https://lingui.dev/ref/cli), message catalog | Hợp lý cho workflow dịch có extraction từ đầu; thêm cấu hình macro/CLI cho codebase này |

`Intl.DateTimeFormat` của trình duyệt đảm nhiệm ngày/tháng/thứ theo `vi-VN` hoặc `en-US`. Không thêm date library hoặc backend tải bản dịch vì hai catalog nhỏ, đi kèm bundle. Không dùng browser-language detector: mặc định phải là tiếng Việt dù ngôn ngữ trình duyệt là English.

## Quy tắc dữ liệu và kiến trúc

- `MemberPreferencesDto.lang` đầu ra chỉ `vi | en`; PATCH chỉ nhận hai mã này. Dữ liệu cũ `English (US)`/`English (UK)` được đọc thành `en`; các lựa chọn cũ còn lại hoặc thiếu ngôn ngữ thành `vi`. Không đổi namespace hoặc xóa dataset để migration.
- Seed mock/API mới đặt `vi`. Không sửa JSON fixture tham chiếu hoặc baseline English lịch sử. Preferences D1 là JSON đã có nên không cần migration schema.
- Không dịch tên người/nhóm/workspace/dự án/công việc/tệp, mô tả hoặc bình luận do người dùng nhập. Tên thật được truyền qua interpolation hoặc render literal; mã status/role/filter và ID giữ nguyên. Status/priority/catalog cố định được dịch lúc hiển thị.
- `packages/ui` chỉ biết React translation context, không import i18next/web/data/router. `domain` giữ thuần; contracts tiếp tục chỉ dùng Zod.
- Chuỗi nguồn English làm key phẳng (`keySeparator: false`, `nsSeparator: false`). Khi thêm nhãn, cập nhật **cả hai** catalog và gọi `t()` tại UI. Chuỗi có tên/số biến động dùng interpolation; plural English dùng hậu tố `_one`/`_other`. Không ghép tên người dùng vào key.
- React escape nội dung lúc render; `escapeValue: false` tránh encode HTML hai lần. Không render bản dịch qua `dangerouslySetInnerHTML`.
- Bản dịch chỉ đổi text và locale. Các snapshot/đo pixel English trước đây vẫn là evidence lịch sử; ảnh mới là kiểm tra giao diện song ngữ, không tuyên bố khớp baseline English.

## Kiểm tra lại

Toolchain: Node `24.13.0`, pnpm `11.19.0`; Chromium theo Playwright của repo.

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm build
pnpm test
pnpm reference:check
pnpm test:i18n
```

Browser harness `pnpm test:i18n:browser` cần web mock trên `5173`, web HTTP trên `5175` (`VITE_DATA_MODE=http`), Worker local trên `8787` và D1 đã migrate/seed riêng. Có thể đổi URL qua `I18N_MOCK_URL`/`I18N_HTTP_URL`; output qua `I18N_EVIDENCE_DIR`.

Các kiểm tra cuối đạt: typecheck 5 packages, lint/boundaries, build 5 packages, 279 tests (93 contracts + 170 web/data + 3 reference + 4 workspace + 9 i18n), browser hai adapter và HTTP bundle 575 modules không có mock/source modules. Source tham chiếu được kiểm chứng 86 file, nguyên SHA.

Harness kiểm tra mặc định, hai option, chuyển hai chiều và reload, desktop/mobile không overflow ngang, 16 route ở mỗi adapter, page errors, lưu API thất bại/retry và bootstrap chỉ thay đổi `preferences.lang`. [Kết quả trình duyệt](evidence/i18n/browser.json), ảnh và log kiểm tra nằm trong `evidence/i18n/`; [verification.json](evidence/i18n/verification.json) ghi kết quả lệnh thực tế.

Chưa deploy production; kiểm thử HTTP dùng Worker/D1 local. Auth/provider/billing demo vẫn theo capability hiện có của dự án.
