## Phạm vi triển khai

1. Tạo `TaskTable`, row/cell renderers với đúng 11 cột nguồn; title luôn hiển thị và sticky. Giữ width mặc định, column presets và quy tắc ẩn project column trong project scope. Workspace Table gắn vào page; Project/saved-view Table variants dùng feature harness trước khi tích hợp full ProjectPage ở WU-16.
2. Dùng lại fields, sort/group models, task-open/context commands và mutations từ task feature. Hỗ trợ sửa title/estimate, field popovers, resize tối thiểu 64px và lưu column widths theo view state.
3. Giữ table-specific markup/geometry, header sort, sticky title, horizontal scroll và New task row. Nguồn không có selection checkbox/bulk bar trong TaskTable; không đưa các UI đó từ TaskList sang.
4. Ở viewport ≤ 640px dùng card presentation riêng của source, không ép bảng desktop thu nhỏ. Giữ mobile content/fields, trạng thái rỗng, focus và scroll đúng.
5. Chỉ dùng headless table logic nếu vẫn giữ được behavior và DOM geometry đã xác minh; TanStack Router không phải lý do tự thêm TanStack Table.

## Acceptance criteria

- **WU-13-AC1:** Table Workspace/Project dùng cùng core component; Workspace page và Project/saved-view harness có evidence riêng, không claim full ProjectPage trước WU-16. Field edits cập nhật List/Board/Drawer và task record chung.
- **WU-13-AC2:** Hide/show/resize/sort/group, sticky title, New task/context actions và edit focus khớp source; title không bị ẩn. Không có cột chọn hoặc bulk bar mới.
- **WU-13-AC3:** Desktop, bảng đã cuộn ngang và mobile card states có đối chiếu ảnh/tương tác tại các biên 640px/641px; lỗi edit giữ draft.

## Verification bắt buộc

- Kiểm tra inline edit validation, resize/column persistence, sort/group, context action và suppress-click sau resize.
- Đối chiếu desktop/sticky/scrolled columns cùng mobile cards ở 640px/641px; chạy typecheck/build.
- Dùng script thực tế của repo; nếu tên script trong tài liệu chưa có, tạo hoặc ghi tên tương đương có thật trong phạm vi unit. Ghi command, exit status, artifact và lỗi còn lại. Không ghi “pass” khi chưa chạy.
