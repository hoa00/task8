## Phạm vi triển khai

1. Mở rộng repo thành apps/web, apps/api, packages/ui, packages/contracts, packages/domain; cấu hình pnpm workspaces và Turborepo tối thiểu.
2. Resolve stable compatible versions, pin Node/pnpm/toolchain và lockfile; kiểm tra peer ranges. Giữ runner capture WU-00 hoạt động.
3. Tạo React TypeScript Vite entry, API package skeleton và exports/types đúng chiều; chưa có business routes. Cấu hình build/lint/typecheck/test scripts có thật.
4. Thiết lập TanStack Router plugin trước React, routeTree.gen.ts do generator quản lý và được commit; bỏ lint/format generated file.
5. Tạo public/private env typed: mock/http mode cho web, API URL tương đối; không đặt secrets vào VITE_*; ghi scripts và cách chạy local.

## Acceptance criteria

- **WU-01-AC1:** Clean pnpm install --frozen-lockfile và typecheck/build thành công, không cần file generated ngoài Git để typecheck.
- **WU-01-AC2:** Không import app vào packages; ui/contracts/domain không kéo Worker bindings/Hono vào browser.
- **WU-01-AC3:** Turbo graph tối thiểu đúng dependencies; source capture WU-00 vẫn chạy.

## Verification bắt buộc

- pnpm install --frozen-lockfile; chạy scripts typecheck/build/lint đã tạo.
- Inspect output/graph để bảo đảm source legacy không nằm trong target bundle.
- Dùng script thực tế của repo; nếu tên script tài liệu chưa tồn tại, tạo/ghi tên tương đương có thật trong phạm vi unit. Ghi command, exit status, artifact và lỗi còn lại. Không ghi “pass” khi chưa chạy.

## Quy trình và điều kiện dừng

Trước khi sửa: inspect implementation + PROGRESS; xác minh prerequisite; đưa kế hoạch ngắn 3–7 bước. Sau đó implement ngay trong session. Không làm unit sau, không refactor ngoài phạm vi, theo convention và chỉ thêm tests cần cho unit.

Trước khi kết thúc: chạy verification, sửa lỗi do work, cập nhật PROGRESS với acceptance/evidence/conflicts/blockers, commit thay đổi thuộc unit, push repo đích `main` đã cấu hình theo AGENTS, báo kết quả bằng tiếng Việt rồi dừng.

Chỉ đánh dấu **DONE** khi mọi AC và gate bắt buộc đạt. Thiếu browser/source baseline/DB binding/quyền push phải báo riêng đúng bước; không bịa kết quả. Code chưa đạt thì **IN_PROGRESS** hoặc **BLOCKED**, không nhảy qua unit tiếp theo.
