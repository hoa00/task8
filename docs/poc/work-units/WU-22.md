## Phạm vi triển khai

1. Dùng lại `FileTypeIcon`, `FilePreviewArt`, `AttachmentCard`, `Dropzone`, `UploadProgress` và `FilePreviewDialog` từ WU-10/11. Mở rộng thành `FileCard`/`FileRow` và Project Files page; không viết lại renderer preview hoặc attachment riêng cho page này.
2. Hoàn thiện Grid/List, query/type/sort và cả 8 file types của source. Giữ artwork/thumbnails mẫu bằng CSS/SVG, metadata, empty states và dropzone geometry; không biến sample art thành tuyên bố đã có bytes thật.
3. Bổ sung mock rename/duplicate/delete và các integration upload cần cho catalogue vào file operations canonical. Một file record có một ID, taskId có thể null; rename/remove/delete/Undo đồng bộ với Drawer, không đối chiếu hoặc xóa theo filename.
4. Chốt Copy link bằng URL `/w/$workspaceId/projects/$projectId/files?fileId=$fileId`. Validate file thuộc workspace/project và permission hiện hành; mở trực tiếp tải dữ liệu rồi mở preview, invalid/deleted file có trạng thái đúng. Close/Back/Forward không gọi history back mù khi URL được mở trực tiếp.
5. Nối link từ FilePreviewDialog, context menu, Search/Palette và attachment liên quan bằng cùng builder/controller; đóng Files tab pending WU-16 và file-link pending WU-18. Preview link đến task dùng TaskDrawer controller hiện có.
6. Giữ upload progress/error/cancel state đúng mock capability. HTTP upload bytes và R2 transport nối ở WU-35; source sample provenance được ghi rõ, không dựng folder tree hoặc cho mock progress thành bằng chứng upload thật.

## Acceptance criteria

- **WU-22-AC1:** Một file record hiển thị nhất quán ở Files và TaskDrawer; rename/delete/remove/Undo dùng contract, duplicate có ID mới và không tạo attachment identity thứ hai.
- **WU-22-AC2:** Upload error/cancel/progress không báo thành công khi flow fail; mock scenarios được phân biệt rõ với HTTP capability. Foundation từ WU-10/11 được reuse bằng imports.
- **WU-22-AC3:** Cả 8 artwork types, grid/list/preview/dropzone/empty states có reference comparison; Project Files body hoàn tất và không còn placeholder trong tab này.
- **WU-22-AC4:** Copy link, direct load, reload, Back/Forward và Close của file preview hoạt động; file không tồn tại/khác project/khác workspace/không được phép không làm lộ nội dung. Search/Palette/file/task links liên quan đã đóng pending.

## Verification bắt buộc

- Kiểm tra file identity/linkage, rename/duplicate/delete/remove/Undo, mock upload error/cancel và invalidation về Drawer.
- Kiểm tra canonical deep links, scope validation, direct entry/reload/Back/Close và Search/Palette integration.
- Đối chiếu Files/attachments/preview ở 8 file types và desktop/mobile; chạy typecheck/build.
- Dùng script thực tế của repo; nếu tên script trong tài liệu chưa có, tạo hoặc ghi tên tương đương có thật trong phạm vi unit. Ghi command, exit status, artifact và lỗi còn lại. Không ghi “pass” khi chưa chạy.
