## Phạm vi triển khai

1. Triển khai Security password/sessions/2fa và Billing plan/payment/invoices với đúng source visuals/copy/states. Giữ đủ 6 sections, không bỏ vì backend production nằm ngoài phạm vi.
2. Dùng demo service facade/scenarios tách khỏi StudioApi HTTP auth/payment, với fixtures và clock xác định cho validation/loading/error/setup/completed states.
3. Mở rộng PasswordInput base thành shared PasswordStrength presentation để Auth WU-26 dùng lại; dùng Dialog/Confirm/SettingRow hiện có. Plan cards, session rows và invoice table giữ presentation riêng của source.
4. HTTP mode với capability unavailable không đổi password/plan/2FA hoặc session principal thật, không hiển thị thành công giả. Demo vẫn mở và kiểm tra đầy đủ bằng scenario tường minh.
5. Giữ source actions: password validation/save demo, session sign-out confirmation, 2FA setup/invalid/enabled/disable, upgrade/downgrade confirmation. Payment Update/Edit chỉ phản hồi demo như nguồn; invoices là bảng read-only.

## Acceptance criteria

- **WU-25-AC1:** Cả 6 sections và các source states tương ứng có demo coverage/reference comparison; không bị coi là ngoài scope UI.
- **WU-25-AC2:** Mã 2FA 6 chữ số và password demo không trở thành access control. Không thêm annual/monthly toggle, card-entry form hoặc invoice-download action mà nguồn không có.
- **WU-25-AC3:** Controls, copy, typography, loading/error/disabled và confirmation states khớp source; action behavior được phân loại rõ theo mode/capability.
- **WU-25-AC4:** PasswordInput/Strength được xuất dùng chung cho Auth, không tạo form state hoặc backend credential record ngoài demo boundary.

## Verification bắt buộc

- Kiểm tra demo state transitions, errors, disabled/focus và HTTP capability-unavailable behavior bằng fixtures xác định.
- Đối chiếu Security/Billing variants trên desktop/mobile; chạy typecheck/build.
- Dùng script thực tế của repo; nếu tên script trong tài liệu chưa có, tạo hoặc ghi tên tương đương có thật trong phạm vi unit. Ghi command, exit status, artifact và lỗi còn lại. Không ghi “pass” khi chưa chạy.
