# FR-04 decisions, owners and rollback

Date edits: contracts reject a start after a due date. Reference `actions/actions.js:620` clamps a form start at submit; drag-drop.js:187-189 and264 preserves duration. Existing target List/Drawer clamped due crossings, Table clamped either endpoint, and new drafts kept independent values. The chosen explicit policy keeps record intervals valid by clamping the other endpoint on either crossing; null clears only the selected field. Draft inputs stay independent and existing schema validation remains the submit boundary. Calendar/Timeline rescheduling keeps its separate duration policy. This deliberately changes start-date crossing behavior for record editors to match Table; it does not silently clamp invalid drafts on submit.

Web task-view owns column names/pixels/hidden columns/width validation. Domain owns strict query normalization, filtering, ordering, grouping and dates; presentation compatibility removed. All web and non-API test consumers migrated. No API consumers used the removed presentation exports.

`loadTaskViewDataset` is the complete catalogue owner with cursor repetition and summary coverage guards. `task-dataset-key` removes page cursor/limit and normalizes the scope. List and Board/Table hooks share that cache value and loader; list selects items. Overlay enables full catalogue only for an open form or dependency editor; drawer uses getTask. Browser counts: Settings0 catalogue requests, Home1list+1summary, unopened drawer0list, dependency editor1list.

Notification feed pending/error are owned by the feed query. Per-item task enrichment can fail independently; errored task results (including cached DTOs) are not exposed. Feed/list/Inbox remain available for403/404/500. Backend feed visibility and canonical notification contract remain authoritative.

AppServicesProvider (inside OverlayProvider, outside business providers, workspace lifetime) owns notice/Undo and surface revision; surface-motion owns route/page animation. Project intents contain only project commands. Project overlay changes report a revision in layout effect with a stable surface callback; unrelated features use app services directly. Explicit Undo uses the captured client intent and invalidates affected projections. Source CSS/tokens and reduced-motion rules are unchanged.

Project view decoding/default restore is pure with respect to writes. Storage reads accept a controlled read interface, malformed data falls back; only explicit change actions persist. Saved route beforeLoad validates/awaits definitions, retaining the prior route while pending. New URL state wins when the delayed definition arrives. Browser spies report no project preference writes on render.

List/Board/Table controllers own command/draft/drag/Undo lifecycle and compose per-record controllers through typed row/card slots. Their controlled `*View` modules have no runtime controller/data imports; guard rejects an indirect component-controller dependency. Shared settings headings/rows moved out of the route layout into SettingsComponents. Row/card/cell controller wrappers own data/command hooks and pass typed date/patch/rename models to separate controlled views. PropertyGrid and Subtasks receive today. FileFoundation contains presentation only; FilePreviewDialog is a separate query controller. TaskDrawer/TaskFormDialog/TaskConversation, ProjectFormDialog/ShareDialog and InboxPreview are explicitly controllers (they orchestrate commands/queries and compose controlled fields/comments), correcting the old view inventory. DirectoryMember presentation model has a feature owner; invite validation is one pure domain function used independently by view and adapter. Public imports name only real controller/hook/model/policy consumers; no wildcard public barrels added. All89 FR-04 exceptions removed; frozen ceiling unchanged and negative boundary tests continue to reject new violations.

Persisted task/project/mock data, preference namespaces and shapes are unchanged. Rollback the structural commit and restore moved presentation exports with its consumers together; no reset/migration required. The independent baseline formatting commit preserves emitted JSX text and JavaScript syntax (ordinary Prettier can otherwise collapse existing inline spaces). Historical source/visual debt remains unchanged. Initial browser harness attempts used an incorrect selector/search key, default Vietnamese labels, and expected a loading view despite the route's beforeLoad guard; failure/cancellation records are retained. Final suites use actual route/schema/locale and validate the held route then current URL preference.

Explicit view-controller negative coverage protects this boundary. No work was discarded.
